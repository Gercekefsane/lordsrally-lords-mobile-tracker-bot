# Lords Mobile Bot Commands

The LordsRally bot exposes **79 commands across 11 categories**, each with localised names, arguments and help text in **7 languages**.

> 📋 The interactive, always-current list lives on the website: **[lordsrally.com/commands](https://lordsrally.com/commands)**
> Command availability and names are shown there in your own language.

## Categories

| Category | Commands | Covers |
|---|---|---|
| Tracking | 18 | Player and kingdom movement tracking |
| Kingdom | 11 | Kingdom-level queries and status |
| War | 10 | War and rally support |
| Tiles | 9 | Resource tiles and farming |
| Wonder | 9 | Wonder occupancy and control |
| Migration | 6 | Kingdom transfer |
| Search | 6 | Player search |
| Inactive scan | 3 | Finding inactive players |
| Scout | 3 | Reconnaissance |
| General | 2 | Shared utilities |
| Guild | 2 | Guild-level queries |

## How commands are used

Commands are addressed to the platform's bot in the channel where it operates. Each command takes arguments (player name, kingdom number, coordinates, …) and answers in the language your account is set to.

The website documents each command with:

- its **name in all 7 languages**
- the **arguments** it accepts
- a short **description** of what it does

👉 **[See all 79 commands](https://lordsrally.com/commands)**

## Notes

- Command lists change as the platform gains capabilities. The count on this page mirrors the live product (**79** at the time of writing) — the website is always authoritative.
- Not every command is available in every package; availability follows the package you hold.
