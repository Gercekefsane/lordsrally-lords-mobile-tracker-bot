# How LordsRally Works

LordsRally is one platform with one account and one balance, covering four products for Lords Mobile.

## One account, one balance

- **One registration** — a single account works for every product.
- **One USD balance** — you top up once; bot packages, RSS accounts and Bulk Message all draw from it.
- **One transaction history** — every movement is listed in your account, so you can reconcile it yourself.
- **Verified phone** — ordering requires a verified number, so delivery notices reach you.
