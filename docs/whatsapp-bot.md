# WhatsApp Bot — Alerts Where You Actually Look

LordsRally delivers bot alerts over **WhatsApp** as well as Telegram. Instead of watching a dashboard, you get the event pushed to the messenger you already have open.

> 📱 **How to connect:** open **[lordsrally.com](https://lordsrally.com)** and use the **WhatsApp** contact / connect button. The button is on the site — we do not publish a contact number here (see [Privacy](#privacy)), and numbers are never posted in this repository.

---

## What arrives on WhatsApp

| Alert | When |
|---|---|
| Enemy castle detected | A target matching your watch rules becomes visible |
| Shield drop | A watched player's shield is down |
| Rally / war activity | A rally or attack involving your kingdom is seen |
| Player movement | A tracked player moves kingdom or changes alliance |
| Command output | The result of the commands you run — see [commands](commands.md) |

Alerts are **automatic**: once the bot is bound to your guild/kingdom, the watch rules run on schedule and push to WhatsApp and Telegram.

## WhatsApp vs Telegram

| | WhatsApp | Telegram |
|---|---|---|
| Automatic alerts | ✅ | ✅ |
| Command output | ✅ | ✅ |
| Commands with buttons | — | ✅ |
| Setup | Connect via the site | Connect via the site |

Both channels run the **same platform** and the same command engine. You choose per target where you want alerts delivered.

## WhatsApp in the platform

- **System messages** (delivery notices, security messages) can reach you over WhatsApp after you verify a number once.
- **DEMO** — the site shows WhatsApp command output live, so you can see it before connecting: [See Live Demo](https://lordsrally.com).

## Privacy

- **We never post a contact number** in this repository or anywhere public. All connecting happens through **[lordsrally.com](https://lordsrally.com)**.
- Customer data (numbers, order details) is never disclosed to third parties — see the full policy at [lordsrally.com/privacy](https://lordsrally.com/privacy).
- The bot speaks in **7 languages**, so notifications arrive in your own language.

## Frequently asked

**Is this WhatsApp spam / bulk messaging to strangers?**
No. WhatsApp is used to send **you** your own bot's alerts. Bulk outreach is a separate product that delivers **in-game mail** inside Lords Mobile — see [Bulk Message](bulk-message.md).

**Do I have to use WhatsApp?**
No. Telegram works on its own; you can use either or both.

**Why isn't there a phone number on this page?**
By design — the platform's contact number is deliberately not published on public surfaces. Start from the site.
